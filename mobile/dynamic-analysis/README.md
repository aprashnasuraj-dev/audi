# Dynamic Mobile Analysis

Dynamic mobile analysis is intentionally documented as a **private lab workflow** and is not wired into GitHub Actions.

Allowed private-lab purpose:

- observe researcher-owned sessions;
- confirm whether a static candidate has direct Minly backend/session/data impact;
- avoid root/jailbreak-only claims.

Not included here:

- scripts to bypass root/jailbreak detection;
- crypto-hooking snippets;
- certificate-pinning bypass tooling;
- automated interception against live users.

Those techniques may be legitimate in some authorized labs, but this public VDP repository should not ship turnkey bypass scripts or run them in CI.
